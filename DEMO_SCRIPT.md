# KDP MART — Demonstration Script

1. Login as customer (registered account) → dashboard.
2. Browse products, search, view details.
3. Add to cart and wishlist; apply coupon.
4. Checkout with COD or sandbox payment (test credentials).
5. View order history, invoice PDF.
6. Login as seller → manage products, view orders, reports.
7. Login as delivery partner → assigned deliveries, update status.
8. Login as admin → dashboard, users, orders, coupons, reports.
9. Smart Coins: view wallet, redeem, transaction history.
10. Returns/refunds flow (if applicable).
Adjust sequence to features that work in the environment.
